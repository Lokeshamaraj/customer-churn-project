# Customer Churn Analysis & Prediction

##  Project Overview

This project analyzes customer churn behavior in a telecom company using data analysis, machine learning, and business intelligence tools. The goal is to identify key factors influencing churn and build an interactive dashboard for business insights.

---

##  Key Insights

* 📌 Overall churn rate is approximately **26%**
* 📌 Customers with **month-to-month contracts** have the highest churn
* 📌 Long-term contracts (**1-year, 2-year**) show lower churn rates
* 📌 Dataset is **imbalanced**, with more non-churn customers
* 📌 Fiber optic users tend to have higher churn
